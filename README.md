# Horizon

Научно-популярный сайт о космосе на **React + Vite + Tailwind CSS + React Router**, на трёх языках (RU / EN / KG).

## Запуск

```bash
npm install
cp .env.example .env    # по желанию: вписать свой ключ NASA API
npm run dev             # http://localhost:5173
npm run build && npm run preview
```

## Страницы

| Маршрут | Содержание |
|---|---|
| `/` | Hero, счётчики, NASA APOD (фото/видео дня), обзор разделов, «Космический кинозал» (`/#cinema`), карточки-факты |
| `/solar-system` | Орбитальная карта, 8 карточек планет с модальными окнами, сравнительные шкалы (диаметр, расстояние, температура, гравитация, год), калькулятор веса |
| `/stars` | Спектральные классы O–M, интерактивный жизненный цикл (2 пути), сравнение размеров, знаменитые звёзды |
| `/galaxies` | Типы галактик, схема Млечного Пути, Андромеда, галерея «Хаббл»/«Уэбб» с фильтром и лайтбоксом |
| `/black-holes` | Интерактивная анатомия, способы образования, калькулятор радиуса Шварцшильда, знаменитые чёрные дыры |
| `/universe` | Лестница масштабов, история Вселенной, состав (тёмная энергия/материя), великие тайны |
| `/credits` | Итоги аудита лицензий, таблицы авторства всех изображений и видео |

## Архитектура

```
src/
  i18n/LanguageContext.jsx   # React Context: lang, t(key), tr({ru,en,kg}), nf(); язык хранится в localStorage
  i18n/ui.js                 # словарь интерфейса
  data/planetsData.js        # массив планет (все тексты на 3 языках)
  data/starsData.js, galaxiesData.js, blackHolesData.js, universeData.js, homeData.js
  data/images.js             # реестр изображений с точными строками авторства и лицензией
  data/sourcesData.js        # источники внизу каждой страницы
  data/videosData.js         # реестр видео: категория, ссылки на файлы, заголовок/описание (RU/EN/KG), кредит, лицензия
  components/video/          # VideoPlayer, VideoCredit, VideoCard, VideoShowcase (блок в разделах), CinemaSection (главная)
  components/                # Header, Footer, Starfield (canvas), Modal, SpaceImage, Credit, ApodSection…
  pages/                     # страницы (ленивая загрузка, кроме главной)
```

## Лицензии изображений

- **NASA** — не защищены авторским правом в США; NASA указывается как источник; логотипы NASA не используются; одобрение NASA не подразумевается.
- **ESA/Webb, ESA/Hubble** — CC BY 4.0; полная неизменённая строка авторства с активной ссылкой рядом с каждым снимком; логотипы ESA не используются.
- **NASA APOD** — изображение загружается напрямую с серверов NASA; поле `copyright` из API всегда отображается.

Снимки не хранятся в репозитории — они загружаются с официальных CDN (images-assets.nasa.gov, cdn.esawebb.org, cdn.esahubble.org).

## Видео («Космический кинозал»)

- 15 роликов из **NASA Image and Video Library** и **ESA/Hubble Videos**, 5 категорий: планеты, звёзды, галактики, чёрные дыры, космос.
- Файлы MP4 (H.264/AAC) воспроизводятся нативным `<video>` прямо с `images-assets.nasa.gov` и `cdn.esahubble.org` — без YouTube-трекинга и без проблем с CORS. До нажатия Play загружается только постер; на телефонах и при Save-Data выбирается облегчённая версия файла; при ошибке — автоматический повтор с другой версией.
- Под каждым плеером — полная строка авторства, ссылка на страницу источника и лицензию. Ролики со сторонними материалами (NASA) или с музыкой под отдельными правами (ESA/Hubble) намеренно исключены.
- Чтобы добавить видео, допишите объект в `src/data/videosData.js` через хелперы `nasaVideo(nasaId)` / `hubbleVideo(id)` и скопируйте кредит со страницы ролика дословно.

## Деплой

Используется `BrowserRouter`: на статическом хостинге настройте fallback всех путей на `index.html` (Netlify: `public/_redirects`, Vercel: `vercel.json` rewrites).
